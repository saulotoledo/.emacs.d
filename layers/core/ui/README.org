* Emacs Configuration
** Color Preview (Colorful Mode)
~colorful-mode~ is a minor mode that allow highlight and preview of colors
(e.g., hex and color names) in the current buffer in real time. It is based on
the classic =rainbow-mode.el=, but uses overlays instead and is more modern.

#+begin_src emacs-lisp
(use-package colorful-mode
  :custom
  (colorful-add-hex-colors t)
  (colorful-add-color-names t)
  (colorful-add-css-variables-colors t)
  (colorful-add-rgb-colors t)
  (colorful-add-oklab-oklch-colors t)
  (colorful-add-hsl-colors t)
  (colorful-add-latex-colors t)
  (colorful-use-prefix t)
  (colorful-only-strings 'only-prog)
  (css-fontify-colors nil)
  :config
  (global-colorful-mode t)
  (add-to-list 'global-colorful-modes 'helpful-mode)
  (add-to-list 'global-colorful-modes 'org-mode))
#+end_src

** Terminal Resize & Geometry Recovery
When moving a terminal window between monitors or resizing it quickly, Emacs
running in a tty can briefly see inconsistent size or DPI info. That can make
Emacs compute the wrong number of rows/columns and push lines or UI elements
off-screen even though the terminal already grew.

The root causes are timing and handshake differences between the terminal
emulator and Emacs (TERM or DPI changes and delayed resize notifications). The
terminal may update geometry after Emacs has already calculated layout.

As a workaround, we force an immediate redisplay, a gentle recenter, and a few
retry attempts after short delays; as a last resort it re-applies the frame
size. These retries catch late-arriving terminal updates and bring Emacs' view
into alignment with the terminal once the emulator finishes reporting geometry.

The code only runs for non-graphical (tty) sessions and uses safe ignore-errors
wrappers, so risk is low.

#+begin_src emacs-lisp
(defun cfg-core/tty-resize-fix (&rest _args)
  "Robustly fix terminal/frame resize artifacts.
When running in a terminal, some resize events (DPI/monitor switch)
leave the UI in a bad state. Try several redisplay/recenter attempts
and a safe frame-size reapply as a fallback."
  (interactive)
  (let ((dap-active (and (fboundp 'dap--cur-session) (dap--cur-session))))
    (unless dap-active
      (ignore-errors
        (when (not (display-graphic-p))
          (redisplay)
          (run-with-idle-timer 0.03 nil (lambda () (redisplay)))
          (run-with-idle-timer 0.07 nil (lambda () (redisplay) (ignore-errors (recenter 0))))
          (run-with-idle-timer 0.15 nil
                               (lambda ()
                                 (redisplay)
                                 (ignore-errors (recenter 0))
                                 (when (fboundp 'set-frame-size)
                                   (let ((fw (frame-width)) (fh (frame-height)))
                                     (set-frame-size (selected-frame) fw fh))))))))))

(add-hook 'window-size-change-functions #'cfg-core/tty-resize-fix)
(add-hook 'frame-size-change-functions #'cfg-core/tty-resize-fix)
(add-hook 'window-configuration-change-hook #'cfg-core/tty-resize-fix)
#+end_src

** Trailing Newline Indicator

Trailing newline indicator is my own package. It displays a customizable visual
indicator (⏎ by default) in the left margin for the trailing newline at the end
of a file in Emacs. Optionally shows the next line number, making it clear where
the file ends.

#+begin_src emacs-lisp
(use-package trailing-newline-indicator
  :init
  (global-trailing-newline-indicator-mode 1)
  (setq trailing-newline-indicator-show-line-number t))
#+end_src

** Typography & Faces
Configure fixed-pitch monospace and variable-pitch fonts, falling back
gracefully if preferred font families are unavailable on the host system.

#+begin_src emacs-lisp
(when (member "Roboto Mono" (font-family-list))
  (set-face-attribute 'default nil :font "Roboto Mono" :height 108)
  (set-face-attribute 'fixed-pitch nil :family "Roboto Mono"))

(when (member "Source Sans Pro" (font-family-list))
  (set-face-attribute 'variable-pitch nil :family "Source Sans Pro" :height 1.18))
#+end_src
