#+TITLE: Core Package Compatibility Layer
#+CATEGORY: core
#+LAYER_PRIORITY: 10
#+PROPERTY: header-args:emacs-lisp :tangle yes

* Description
Provides the shared package dependencies that must be initialized before the
rest of the configuration. This layer is intentionally one of the first to be
loaded so packages can rely on compatible versions of common libraries.

* Emacs Configuration
** Introduction to the Compatibility Dependencies
Emacs includes several libraries that are also distributed through ELPA. The
built-in copies are stable, but they can be older than the APIs expected by
newer packages. We therefore install and load sufficiently recent external
versions when necessary, maximizing compatibility across the configuration.

These dependencies are shared by many packages, including tools that build
transient menus such as =magit= and =rg=.

*** Compat
~compat~ provides forward-compatibility definitions for Emacs APIs and macros
that packages may use while supporting multiple Emacs releases. A bundled copy
can therefore be older than the compatibility level expected by a current
package, especially when that package was developed against newer Emacs APIs.

*** Transient
~transient~ provides the command-dispatch menus used by Magit and several other
interactive tools. Its internal and macro APIs evolve along with its clients;
the bundled version may lack functions required by newer packages, such as the
layout API used by =rg=, =npm=, and =eca=.

*** Cond-Let
~cond-let~ supplies conditional binding macros used by modern package code and
by newer Transient releases. It is not guaranteed to be upgraded merely because
another package depends on it, so it is declared here as a shared dependency
with an explicit minimum version.

** Emacs Setup
#+begin_src emacs-lisp
(defconst cfg-core/package-minimum-versions
  '((compat . "30.1.0.0")
    (transient . "0.9.2")
    (cond-let . "1.1"))
  "Minimum external versions for shared package compatibility dependencies.")

(defun cfg-core/ensure-package-minimum-version (package minimum-version)
  "Ensure external PACKAGE is installed at least at MINIMUM-VERSION.

Unlike `package-installed-p', this checks `package-alist' so an Emacs-bundled
copy does not satisfy the requirement when an external package is needed."
  (let* ((description (car (alist-get package package-alist)))
         (installed-version
          (and description
               (package-desc-version description)))
         (minimum (version-to-list minimum-version)))
    (when (or (null installed-version)
              (version-list-< installed-version minimum))
      (package-install package))))

(dolist (dependency cfg-core/package-minimum-versions)
  (cfg-core/ensure-package-minimum-version (car dependency) (cdr dependency)))

(use-package compat
  :ensure nil
  :demand t)

(use-package transient
  :ensure nil
  :demand t)

(use-package cond-let
  :ensure nil
  :demand t)
#+end_src
