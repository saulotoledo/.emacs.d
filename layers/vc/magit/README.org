#+TITLE: Magit Layer
#+CATEGORY: vc
#+PROPERTY: header-args:emacs-lisp :tangle yes

* Description
Provides full Git integration using Magit and Forge, supporting repository
inspection, commit staging, PR/issue management, and real-time ANSI process output styling.
Also integrates Git status icons into the Treemacs sidebar via ~treemacs-magit~.

* Emacs Configuration
** Magit Main Setup
#+begin_src emacs-lisp
(use-package magit
  :commands magit-status)
#+end_src

** Treemacs Integration
#+begin_src emacs-lisp
(use-package treemacs-magit
  :after (treemacs magit))
#+end_src

** ANSI Color Support in Magit Process Buffer
#+begin_src emacs-lisp
(defun cfg-vc/magit-color-buffer (proc &rest _args)
  "Apply ANSI colors to the magit-process buffer in real-time.
PROC is the process object for the magit-process buffer."
  (with-current-buffer (process-buffer proc)
    (read-only-mode -1)
    (ansi-color-apply-on-region (point-min) (point-max))
    (read-only-mode 1)))

(declare-function ansi-color-apply-on-region "ansi-color")
(advice-add 'magit-process-filter :after #'cfg-vc/magit-color-buffer)
#+end_src

** Forge Integration
#+begin_src emacs-lisp
(use-package forge
  :pin "MELPA Unstable"
  :after magit
  :config)
#+end_src

* Keybindings
#+begin_src emacs-lisp
(cfg-keys/leader-def
  "g"   '(:ignore t :which-key "git")
  "g s" #'magit-status)
#+end_src

* System Setup
No system setup required.
