#+CATEGORY: lang

* Description
Provides automatic Tree-sitter grammar management and code folding for all
programming languages. Uses treesit-auto to transparently redirect major modes
to their tree-sitter (-ts-mode) counterparts, and treesit-fold for
syntax-aware code folding with fringe indicators.

* Emacs Configuration
** treesit-auto: Automatic Grammar Management
Treesit is a modern incremental parsing library that provides fast,
accurate syntax trees for programming languages. Originally known
as ~tree-sitter~, it was included into Emacs 29+ as a built-in
functonality and known as ~treesit~, which provides ~*-ts-mode~
modes with excellent syntax highlighting and structural editing.

Remember to upgrade the versions when possible. New versions might
not be compatible with your current Emacs build.

** treesit-fold: Syntax-Aware Code Folding
~treesit-fold~ is a syntax-aware folding engine built for the Treesit system
in Emacs 29+. Unlike traditional folding that relies on indentation "guessing,"
it uses a concrete parser to identify the precise boundaries of YAML blocks,
maps, and lists. This allows for lightning-fast, reliable collapsing of massive
datasets, often enhanced by visual indicators in the margin that let you
navigate complex hierarchies with the same ease as an Org-mode document.

#+begin_src emacs-lisp
(use-package treesit-fold
  :pin "JCS-ELPA"
  :config
  ;; Enable indicators globally
  (global-treesit-fold-indicators-mode 1)

  ;; Enable folding for all programming modes
  (add-hook 'prog-mode-hook #'treesit-fold-mode)

  ;; --- Performance: Idle-timer debounce for fringe indicators ---
  ;;
  ;; Problem: treesit-fold-indicators--post-command runs synchronously on
  ;; *every* keystroke via post-command-hook. While typing broken/incomplete
  ;; code (common in TS/Next.js), the Tree-sitter parser repeatedly rebuilds
  ;; the CST and Emacs re-renders fringe markers, causing ~11 % CPU usage and
  ;; input lag (see profiler reports).
  ;;
  ;; Fix: Replace the synchronous call with a buffer-local idle timer.
  ;; Each keystroke cancels the pending timer and schedules a fresh one.
  ;; The real update only fires after the user pauses for 0.5 s, meaning
  ;; *zero* indicator overhead while actively typing.
  (defvar-local cfg-lang/treesit-fold-idle-timer nil
    "Buffer-local idle timer for deferred treesit-fold indicator updates.")

  (define-advice treesit-fold-indicators--post-command
      (:around (orig-fn &rest args) idle-debounce)
    "Defer indicator updates to idle time; cancel-on-type for zero typing overhead.
Skip entirely when indicators are not active in this buffer."
    ;; Fast-path: avoid timer churn in buffers where indicators aren't on
    ;; (minibuffer, org-mode, etc.).
    (when (bound-and-true-p treesit-fold-indicators-mode)
      (when (timerp cfg-lang/treesit-fold-idle-timer)
        (cancel-timer cfg-lang/treesit-fold-idle-timer))
      (let ((buf (current-buffer)))
        (setq cfg-lang/treesit-fold-idle-timer
              (run-with-idle-timer 0.8 nil
                (lambda ()
                  (when (buffer-live-p buf)
                    (with-current-buffer buf
                      (ignore-errors (apply orig-fn args))))))))))

  (defun cfg-lang/treesit-fold-toggle-all ()
    "Toggle all folds in the current buffer."
    (interactive)
    (if (bound-and-true-p cfg-lang/treesit-folded-p)
        (progn (treesit-fold-open-all) (setq-local cfg-lang/treesit-folded-p nil))
      (progn (treesit-fold-close-all) (setq-local cfg-lang/treesit-folded-p t))))

  ;; Global Keybindings (using 'C-c f' as a mnemonic for Fold)
  (keymap-global-set "C-<tab>" #'treesit-fold-toggle)
  (keymap-global-set "C-c v f" #'treesit-fold-toggle)
  (keymap-global-set "C-c v F" #'cfg-lang/treesit-fold-toggle-all))
#+end_src

* Keybindings
Keybindings are set globally in the config above:
- =C-<tab>=: Toggle fold at point
- =C-c v f=: Toggle fold at point
- =C-c v F=: Toggle all folds in buffer

* System Setup
No system setup required. Grammar installation is automatic via =treesit-auto=.
