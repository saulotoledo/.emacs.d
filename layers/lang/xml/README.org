* Description
Configure XML support.

* Emacs Configuration
#+begin_src emacs-lisp
(cfg-editor/register-treesit-auto-language
 'xml
 '("https://github.com/tree-sitter-grammars/tree-sitter-xml" "v0.7.0" "xml/src"))

~nxml-mode~ is the classic Emacs XML mode and is not a tree-sitter
(-ts-) major mode. That means buffers visiting XML with ~nxml-mode~ do
not automatically get a tree-sitter parser attached. Tree-sitter
features require either a treesit-backed major mode (which does not
exist for XML at the moment) or tools that explicitly use the
installed grammar regardless of major mode.

The snippet below enables code folding in ~nxml-mode~ by configuring
the built-in ~hs-minor-mode~ (Hide/Show minor mode) for XML syntax. By
default, ~hs-minor-mode~ does not support XML or SGML out of the
box. This adaptation lets you fold and unfold XML sections, making it
easier to work with large, deeply nested XML files.

The configuration works by adding XML-specific patterns to the
=hs-special-modes-alist=, which tells ~hs-minor-mode~ how to recognize
the start and end of foldable blocks in XML. It also sets up a hook so
that whenever you enter ~nxml-mode~, ~hs-minor-mode~ is automatically
enabled. Furthermore, it customizes the key binding =C-<tab>= to
toggle code folding-but if ~treesit-fold~ is not currently active, to
prevent conflicts.

This solution was adapted from the approach discussed on Emacs Stack
Exchange:
https://emacs.stackexchange.com/questions/2884/the-old-how-to-fold-xml-question

#+begin_src emacs-lisp
(require 'sgml-mode)

(add-to-list 'hs-special-modes-alist
              '(nxml-mode
                "<!--\\|<[^/>]*[^/]>"
                "-->\\|</[^/>]*[^/]>"
                "<!--"
                sgml-skip-tag-forward
                nil))

(add-hook 'nxml-mode-hook
          (lambda ()
            (hs-minor-mode 1)
            ;; Bind C-<tab> to hs toggle only when noxml-fold or treesit-fold
            ;; are not active to avoid conflicts with those handlers.
            (unless (bound-and-true-p treesit-fold-mode)
              (declare-function hs-toggle-hiding "hideshow")
              (local-set-key (kbd "C-<tab>") #'hs-toggle-hiding))))
#+end_src

No keybindings required.

* System Setup
The XML formatter uses ~xmllint~, provided by the libxml2 command-line tools.
This action registers the correct package name for the supported package
managers and makes the executable available to Apheleia.

#+begin_src sh
is_installed__lang__xml__xmllint() {
  command -v xmllint >/dev/null 2>&1
}

register_system_package "xmllint" \
                        "alpine:libxml2-utils" \
                        "fedora:libxml2" \
                        "linuxbrew:libxml2" \
                        "mac:libxml2" \
                        "debian-ubuntu:libxml2-utils"

install__lang__xml__xmllint() {
  install_system_packages "xmllint"
}

uninstall__lang__xml__xmllint() {
  log_skip "xmllint" "xmllint is a system package and will not be uninstalled automatically"
}

register_action "Lang" "XML" "Install xmllint" "-lang--xml--xmllint" "standalone"
#+end_src
