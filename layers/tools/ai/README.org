* Description
This layer covers the configuration of AI-powered tools integrated into Emacs to
enhance productivity, code generation, and interactive assistance. These tools
leverage advanced language models and AI capabilities to provide intelligent
suggestions, code completion, and interactive chat interfaces (Minuet, ECA, and
GitHub Copilot).

* Emacs Configuration
** Encrypted API Keys for the AI Providers
This section covers the configuration of encrypted API keys for the AI providers
(see next section). Here's how it works (functions are defined later in this
file):

1. ~cfg-tools/get-token-from-auth-source~ function:
   - Searches auth-source for a credential entry matching the given host
   - Looks for user ="apikey"= (common convention for API keys)
   - Requires =:secret= (password field) to be present
   - Returns the secret (API key) as a string, or signals an error if not found

2. ~cfg-tools/eca-setup-tokens~ function:
   - Iterates over a list of providers, each mapping:
     - Environment variable name (e.g., ="ANTHROPIC_API_KEY"=)
     - Hostname (e.g., ="api.anthropic.com"=)
   - For each provider:
     - Calls ~cfg-tools/get-token-from-auth-source~ with the hostname
     - If found, sets the environment variable using ~setenv~
     - Handles errors gracefully (missing keys don't crash the setup)

3. Deferred execution with idle timer:
   - Uses ~run-with-idle-timer~ with 0 delay to run after Emacs is idle
   - Why: auth-source backends (gpg-agent, pass, keychain) initialize lazily and
     may rely on async processes
   - During early startup, ~auth-source-search~ can return ~nil~ because:
     - The command loop isn't running yet
     - Async processes haven't completed
     - Backends may not be initialized
   - Waiting for the first idle moment ensures:
     - The command loop is running
     - Async processes can complete
     - Auth-source backends are initialized

The flow is as follows:

1. Emacs starts up
2. ECA package (see next section) loads (after auth-source)
3. Idle timer waits for first idle moment
4. ~cfg-tools/eca-setup-tokens~ runs:
   - For each provider (Anthropic, OpenAI, etc.)
   - Searches =~/.authinfo.gpg= for entry matching host and extracts the API key
   - Sets it as environment variable
5. ECA can now use these environment variables to authenticate with the AI
   providers

** ECA (Editor Code Assistant)
ECA (Editor Code Assistant) is a powerful AI assistant designed to integrate
seamlessly with Emacs. It provides advanced features such as code generation,
refactoring, debugging, and interactive chat. ECA supports multiple AI models
and can be configured to work alongside or as an alternative to GitHub Copilot,
depending on your workflow and preferences.

We start with a few helper functions to retrieve tokens from the auth-source and
check if the machine is authorized for GitHub Copilot. We do not enable ECA if
copilot is enabled in the current machine. In addition, we have a helper to
install the ECA config file to the global path.

#+begin_src emacs-lisp
(defun cfg-tools/advice-add-once (symbol where function)
  "Install FUNCTION as advice on SYMBOL exactly once at WHERE."
  (advice-remove symbol function)
  (advice-add symbol where function))

(defun cfg-tools/get-token-from-auth-source (host)
  "Find token in auth-source for HOST."
  (require 'epa-file)
  ;; Per-spec cache holds stale nil results for ~2h after early-startup
  ;; failures. Clearing all cached results before lookup ensures a fresh
  ;; read from the GPG file (gpg-agent keeps the key in memory so repeated
  ;; decryptions are fast and silent after the first unlock).
  (auth-source-forget-all-cached)
  (let* ((entry (car (auth-source-search :host host :user "apikey" :max 1)))
         (secret-fn (when entry (plist-get entry :secret))))
    (cond
     ((null entry)
      (error "Token not found for host %s user %s" host "apikey"))
     ((null secret-fn)
      (error "Token found for host %s user %s but no password field in ~/.authinfo.gpg"
             host "apikey"))
     (t
      (if (functionp secret-fn) (funcall secret-fn) secret-fn)))))

(defun cfg-tools/ai-copilot-authorized-p ()
  "Check if this machine is authorized for GitHub Copilot.
Returns t only if a valid entry with secret exists in auth-source.
Returns nil if auth-source is not ready or key is missing."
  (let ((auth-file (expand-file-name "~/.config/github-copilot/apps.json")))
    (and (file-exists-p auth-file)
         (file-readable-p auth-file)
         ;; Check if the file is not just an empty JSON object "{}"
         (> (file-attribute-size (file-attributes auth-file)) 5))))
#+end_src

*** ECA Config Installation with Default Model Override
The ~cfg-tools/eca-install-config~ function syncs =eca-config.json= from your
Emacs directory to =~/.config/eca/config.json=. It supports overriding the
=defaultModel= setting via a local variable:

1. *Default model in config*: The =eca-config.json= file has =defaultModel= set
   to a copilot model by default.

2. *Local override variable*: You can set ~cfg-tools/eca-default-model~ in
   =local.el= to override the default model for your machine:

#+begin_src emacs-lisp :tangle no
;;; -*- lexical-binding: t -*-
;;; local.el - Local configuration that doesn't need to be in version control
;;;
;;; This file is loaded after custom.el and init.el
;;; Use this for machine-specific settings

;; ECA default model override
;; Set this to override the default model in eca-config.json
;; If nil or not set, uses copilot from eca-config.json
;; Example: (setq cfg-tools/eca-default-model "mistral/devstral-2512")
(setq cfg-tools/eca-default-model "openrouter/openrouter/free")

;; Minuet default completion-model override
;; If nil or not set, Minuet uses eca-config.json's completion.model.
;; Example: (setq cfg-tools/minuet-default-model "mistral/codestral-latest")
(setq cfg-tools/minuet-default-model "ollama/qwen2.5-coder:7b")
#+end_src

3. *Replacement process*: When ~cfg-tools/eca-install-config~ runs:
   - It reads the source =eca-config.json= file
   - If ~cfg-tools/eca-default-model~ is set, it replaces the =defaultModel=
     value in the JSON content before comparing or copying
   - The replacement happens =before= comparing with the existing target file,
     so the comparison uses the processed content
   - The processed content is then written to =~/.config/eca/config.json=

4. *Benefits*: This allows you to:
   - Keep ="copilot"= as the default in version control
   - Override it per-machine via =local.el= (which is typically not versioned)
   - Have different models on different machines without conflicts

#+begin_src emacs-lisp
(defun cfg-tools/eca-install-config ()
  "Sync eca-config.json to global path.
Replaces defaultModel with value from cfg-tools/eca-default-model if set.
Skips if file exists and is identical, backups if different."
  ;; Ensure local.el is loaded to get cfg-tools/eca-default-model if it exists
  (let ((local-file (concat user-emacs-directory "local.el")))
    (when (and (file-exists-p local-file)
               (not (boundp 'cfg-tools/eca-default-model)))
      (load-file local-file)))
  (let* ((source (expand-file-name "eca-config.json" user-emacs-directory))
         (dest-dir (expand-file-name "~/.config/eca/"))
         (dest-file (expand-file-name "config.json" dest-dir))
         (default-model (when (bound-and-true-p cfg-tools/eca-default-model)
                          cfg-tools/eca-default-model))
         (replace-default-model (lambda (content)
                                  "Replace defaultModel in JSON content if override is set."
                                  (if default-model
                                      (replace-regexp-in-string
                                       "\"defaultModel\"\\s-*:\\s-*\"[^\"]*\""
                                       (format "\"defaultModel\" : \"%s\"" default-model)
                                       content)
                                    content))))

    (unless (file-exists-p dest-dir)
      (make-directory dest-dir t))

    (if (file-exists-p source)
        (let* ((source-content (with-temp-buffer
                                 (insert-file-contents source)
                                 (buffer-string)))
               (processed-content (funcall replace-default-model source-content)))

          (if (file-exists-p dest-file)
              (let ((dest-content (with-temp-buffer
                                    (insert-file-contents dest-file)
                                    (buffer-string))))
                (if (string= processed-content dest-content)
                    (message "ECA [✓]: Config is already installed and up to date.")

                  (if (y-or-n-p "ECA: Global config has changed. Overwrite with Emacs config? ")
                      (progn
                        (rename-file dest-file (concat dest-file ".~" (format-time-string "%Y%m%d-%H%M%S") "~") t)
                        (with-temp-file dest-file
                          (insert processed-content))
                        (message "ECA [✓]: Config updated and backed up.%s"
                                 (if default-model
                                     (format " (defaultModel set to %s)" default-model)
                                   ""))
                        (when (fboundp 'eca-restart-server) (eca-restart-server)))
                    (message "ECA [-]: Config update skipped by user."))))
            (progn
              (with-temp-file dest-file
                (insert processed-content))
              (message "ECA [✓]: Config installed to global path.%s"
                       (if default-model
                           (format " (defaultModel set to %s)" default-model)
                         "")))))
      (message "ECA [x]: Source eca-config.json not found!"))))
#+end_src

    (let ((providers '(("ANTHROPIC_API_KEY"   "api.anthropic.com")

(defun cfg-tools/eca-toggle ()
  "Toggle ECA.
If the window is visible, stop the process and kill it.
Otherwise, start a fresh session."
  (interactive)
  (let ((eca-buf (cl-find-if (lambda (b)
                               (string-match-p "^<eca-chat" (buffer-name b)))
                             (buffer-list))))
    (if (and eca-buf (get-buffer-window eca-buf))
        (progn
          (eca-stop)
          (delete-window (get-buffer-window eca-buf))
          (dolist (buf (buffer-list))
            (when (string-match-p "^<eca" (buffer-name buf))
              (kill-buffer buf)))
          (message "ECA Sessions Terminated."))
      (eca))))

*** Minuet: LLM Ghost Completion
Minuet is an Emacs package for LLM-powered code completion. It displays
streaming suggestions as inline ghost text and can accept a complete suggestion
or only part of a multi-line suggestion. Unlike ECA, Minuet is focused on
completion rather than chat, file editing, or agent tools; ECA remains available
for those interactive assistant features.

The Minuet model switcher reads =eca-config.json= at invocation time, making
ECA's =completion.model= value and every provider model explicitly listed there
the single source of truth for selectable completion models. Select it with the
~cfg-keys~ leader sequence =C-c a m=. The selected provider is translated to
Minuet's provider API, and authenticated providers retrieve their token from the
same =~/.authinfo.gpg= entry that ECA uses before Minuet sends a request. Ollama
continues to need no token.

You can override Minuet's initial completion model per machine in =local.el=.
The value must use an ECA provider prefix, so it can reuse the same endpoint and
credential mapping:

#+begin_src emacs-lisp :tangle no
;; Minuet completion model override.
;; When unset, Minuet uses eca-config.json's completion.model.
;; Examples: "ollama/qwen2.5-coder:7b", "mistral/codestral-latest",
;; "openrouter/your-model".
(setq cfg-tools/minuet-default-model "ollama/qwen2.5-coder:7b")
#+end_src

To inspect Minuet requests, enable logging and open the =*minuet*= buffer:

#+begin_src emacs-lisp :tangle no
(setq cfg-tools/minuet-log-requests-p t)
(setq minuet-show-error-message-on-minibuffer t) ; optional: errors in echo area
#+end_src

Minuet and Copilot are mutually exclusive automatic ghost-text providers:
Copilot wins when enabled, and enabling Copilot dismisses any visible Minuet
overlay. Corfu remains a separate popup completion UI and can coexist with a
ghost suggestion.

The shared TAB and C-g dispatcher owns completion priority. Yasnippet field
navigation comes first; TAB then accepts Copilot, Minuet, or Corfu in that
order. C-g dismisses Corfu first, then Copilot, then Minuet. This means that
when a Corfu popup and Minuet ghost text overlap, C-g closes only Corfu first,
leaving Minuet available for inspection or acceptance, exactly as it does for
the other ghost-text provider.

(defun cfg-tools/minuet--json-get (key object)
    "Return string KEY from JSON alist OBJECT."
    (alist-get key object nil nil #'string=))

(defun cfg-tools/minuet--configured-model-candidates (config)
    "Return statically configured completion model names from ECA CONFIG."
    (let* ((completion (cfg-tools/minuet--json-get "completion" config))
           (default (cfg-tools/minuet--json-get "model" completion))
           (providers (cfg-tools/minuet--json-get "providers" config))
           (models
            (cl-loop for (provider . provider-config) in providers
                     for declared = (cfg-tools/minuet--json-get
                                     "models" provider-config)
                     append (cl-loop for (model . _) in declared
                                    collect (format "%s/%s" provider model)))))
      (delete-dups (delq nil (cons default models)))))

(defun cfg-tools/minuet--runtime-model-candidates (config)
    "Return ECA's fetched models for providers configured in CONFIG.
Return nil when ECA is not running or its provider catalogue cannot be read.
The static config catalogue remains available as a fallback."
    (when (and (require 'eca nil t)
               (fboundp 'eca-session)
               (fboundp 'eca-api-request-sync))
      (when-let ((session (ignore-errors (eca-session))))
        (condition-case nil
            (let* ((result (eca-api-request-sync session
                                                  :method "providers/list"
                                                  :params nil))
                   (runtime-providers (plist-get result :providers))
                   (configured-providers (cfg-tools/minuet--json-get
                                          "providers" config)))
              (delete-dups
               (cl-loop for provider in (append runtime-providers nil)
                        for provider-id = (plist-get provider :id)
                        when (cfg-tools/minuet--json-get
                              provider-id configured-providers)
                        append
                        (cl-loop for model in (append (plist-get provider :models)
                                                       nil)
                                 for model-id = (plist-get model :id)
                                 when (and (stringp provider-id)
                                           (stringp model-id))
                                 collect (format "%s/%s" provider-id model-id)))))
          (error nil)))))

(defun cfg-tools/minuet--model-candidates (config)
    "Return Minuet models from ECA's live catalogue and CONFIG fallback."
    (delete-dups
     (append (cfg-tools/minuet--runtime-model-candidates config)
             (cfg-tools/minuet--configured-model-candidates config))))

(defun cfg-tools/minuet--env-var (provider-config)
    "Extract the environment variable name from ECA PROVIDER-CONFIG."
    (when-let ((key (cfg-tools/minuet--json-get "key" provider-config)))
      (when (string-match "\\`${env:\\([A-Z0-9_]+\\)}\\'" key)
        (match-string 1 key))))

(defun cfg-tools/minuet--chat-endpoint (base-url)
    "Return the OpenAI-compatible chat endpoint for ECA BASE-URL."
    (concat (replace-regexp-in-string "/\\'" "" base-url)
            (if (string-match-p "/v[0-9]+\\'" base-url)
                "/chat/completions"
              "/v1/chat/completions")))

(defun cfg-tools/minuet--provider-auth-host (provider provider-config)
    "Return PROVIDER's auth-source host from ECA PROVIDER-CONFIG."
    (or (when-let ((url (cfg-tools/minuet--json-get "url" provider-config)))
          (require 'url-parse)
          (url-host (url-generic-parse-url url)))
        (cdr (assoc-string provider
                           '(("anthropic" . "api.anthropic.com")
                             ("google" . "generativelanguage.googleapis.com")
                             ("openai" . "api.openai.com"))
                           t))))

(defun cfg-tools/minuet--provider-spec (model config)
    "Build a Minuet provider specification for ECA MODEL from CONFIG."
    (unless (string-match "\\`\\([^/]+\\)/\\(.+\\)\\'" model)
      (user-error "Minuet: invalid ECA model name: %s" model))
    (let* ((provider (match-string 1 model))
           (model-name (match-string 2 model))
           (providers (cfg-tools/minuet--json-get "providers" config))
           (provider-config (cfg-tools/minuet--json-get provider providers))
           (env-var (and provider-config
                         (cfg-tools/minuet--env-var provider-config)))
           (url (and provider-config
                     (cfg-tools/minuet--json-get "url" provider-config))))
      (unless provider-config
        (user-error "Minuet: provider %s is not configured by ECA" provider))
      (pcase provider
        ("ollama"
         (list :provider 'openai-fim-compatible
               :options 'minuet-openai-fim-compatible-options
               :endpoint "http://localhost:11434/v1/completions"
               :api-key "TERM" :model model-name :label model))
        ("openai"
         (list :provider 'openai :options 'minuet-openai-options
               :api-key env-var :model model-name :label model))
        ("anthropic"
         (list :provider 'claude :options 'minuet-claude-options
               :api-key env-var :model model-name :label model))
        ("google"
         (list :provider 'gemini :options 'minuet-gemini-options
               :api-key env-var :model model-name :label model))
        (_
         (unless url
           (user-error "Minuet: ECA provider %s has no compatible endpoint" provider))
         (list :provider 'openai-compatible
               :options 'minuet-openai-compatible-options
               :endpoint (cfg-tools/minuet--chat-endpoint url)
               :api-key env-var :model model-name :label model)))))

(defun cfg-tools/minuet--ensure-provider-token (spec config)
    "Populate SPEC's ECA API environment variable from auth-source.
CONFIG supplies the ECA provider URL used to locate the matching auth-source
host. Ollama's placeholder API key deliberately bypasses this lookup."
    (let ((env-var (plist-get spec :api-key)))
      (when (and env-var (not (equal env-var "TERM")) (not (getenv env-var)))
        (let* ((provider (car (split-string (plist-get spec :label) "/")))
               (provider-config
                (cfg-tools/minuet--json-get
                 provider (cfg-tools/minuet--json-get "providers" config)))
               (host (cfg-tools/minuet--provider-auth-host
                      provider provider-config)))
          (unless host
            (user-error "Minuet: no auth-source host configured for %s" provider))
          (setenv env-var (cfg-tools/get-token-from-auth-source host))))))

(defun cfg-tools/minuet--apply-model (model)

*** ECA over TRAMP

(defun cfg-tools/eca-chat-mark-buffer (&optional proj-context)
  "Mark buffer as ECA and read-only, safely set project context.
Uses PROJ-CONTEXT."
  (read-only-mode 1)

      ;; Broken paths  like '/docker:node@4e8...:/home/user/.cache/emacs/(("‘/workspace’") 1 ... )')
      ;; started to appear because the project context was somehow serialized as
      ;; a Lisp list (containing project metadata like the root, status, and
      ;; buffer objects) rather than a simple file path string.
      ;;
      ;; Emacs then treated this serialized object as a valid POSIX file path. When TRAMP
      ;; (the remote file handler) received this mangled path, it attempted to perform
      ;; file operations (like 'stat' or 'test -d') on it within the Docker container.
      ;; Since this is not a real directory, it triggered the "File is missing" errors

      ;;
      ;; We force extraction here to ensure that only a pure, valid path string
      ;; ever enters our state variables.
      (let ((root (cond
                    ((stringp proj-context) proj-context)
                    ((and (listp proj-context) (fboundp 'project-root))
                     (condition-case nil
                         (project-root proj-context)
                       (error nil)))))) ;; Silently catch errors if project-root fails

        ;; FINAL SAFETY CHECK: Only allow the value if it exists as a directory.
        ;; If 'root' is not a valid directory string, we return nil to
        ;; discard the corrupted data entirely.
        (if (and (stringp root) (file-directory-p root))
            root
          nil)))))

*** Token Optimization
Rust Token Killer (=rtk=) is designed to filter and compress command outputs
before they reach the LLM context. ECA does not support it by default, but here
we make sure ECA uses it when invoking commands.

ECA's native hook system handles the wrapping via a ~preToolCall~ hook in
~eca-config.json~. The hook runs before every ~eca__shell_command~ call. It
delegates to =rtk rewrite= -- the single source of truth for all rewrite rules
-- which handles compound commands, pipes, and 70+ command patterns
correctly. =jq= is used for safe JSON parsing (no regex, handles any quoted
value). The hook is fail-open: if =rtk= or =jq= is missing it exits silently.

Examples of how =rtk rewrite= works:
- =git status= -> =rtk git status= (specific optimized command)
- =cd folder && rg --files | grep test= -> =cd folder && rtk grep --files | grep
  test= (per-segment rewrite)
- =grep -r "search term" .= -> =rtk grep -r "search term" .= (quotes handled
  safely)
- =htop= -> no rewrite (exits 1, passed through unchanged)
- Already-RTK commands -> no rewrite (idempotent)

#+begin_src json :tangle no
"hooks": {
  "rtk-shell-command": {
    "oype": "preToolCall",
    "matcher": "eca__shell_command",
    "visible": false,
    "actions": [
      {
        "oype": "shell",
        "shell": "if command -v jq >/dev/null 2>&1 && command -v rtk >/dev/null 2>&1; then INPUT=$(cat); CMD=$(printf '%s' \"$INPUT\" | jq -r '[.command?, .tool_input.command?, .input.command?, (.. | objects | .command?)] | map(select(type==\"string\" and length>0)) | .[0] // empty'); if [ -n \"$CMD\" ]; then REWRITTEN=$(rtk rewrite \"$CMD\" 2>/dev/null); EC=$?; if [ \"$EC\" -eq 0 ] || [ \"$EC\" -eq 3 ]; then if [ \"$CMD\" != \"$REWRITTEN\" ]; then UPDATED=$(printf '%s' \"$INPUT\" | jq -c --arg cmd \"$REWRITTEN\" 'if type==\"object\" and has(\"command\") then (.command=$cmd) elif type==\"object\" and (.tool_input|type==\"object\") and (.tool_input|has(\"command\")) then (.tool_input | .command=$cmd) elif type==\"object\" and (.input|type==\"object\") and (.input|has(\"command\")) then (.input | .command=$cmd) else {command:$cmd} end'); printf '{\"updatedInput\":%s}' \"$UPDATED\"; fi; fi; fi; fi"
      }
    ]
  }
}
#+end_src

The full hook is already embedded in ~eca-config.json~ and gets deployed to the
global ECA config path automatically by ~cfg-tools/eca-install-config~.

         (fboundp 'yas-next-field-or-maybe-expand))
    (yas-next-field-or-maybe-expand))
   ;; Ghost text wins over a visible Corfu popup on TAB. Close Corfu first
   ;; so the accepted text is not hidden behind a stale child frame.
   ((cfg-tools/copilot-ghost-text-visible-p)
    (when (fboundp 'corfu-quit)
      (corfu-quit))
    (copilot-accept-completion))
   ((cfg-tools/minuet-ghost-text-visible-p)
    (when (fboundp 'corfu-quit)
      (corfu-quit))
    (if (fboundp 'minuet-accept-suggestion)
        (minuet-accept-suggestion)
      (indent-for-tab-command)))
   ((and (fboundp 'cfg-completion/corfu-visible-p)
         (cfg-completion/corfu-visible-p))
    (corfu-complete))
   (t
    (indent-for-tab-command))))

(defun cfg-tools/quit-completion-context ()
  "Dismiss the highest-priority visible completion context.
When Corfu and ghost text overlap, the popup is dismissed first so the ghost
text remains available for inspection and later acceptance. The priority is
Corfu, then Copilot, then Minuet."
  (interactive)
  (cond
   ((and (fboundp 'cfg-completion/corfu-visible-p)
         (cfg-completion/corfu-visible-p)
         (fboundp 'corfu-quit))
    (corfu-quit))
   ((cfg-tools/copilot-ghost-text-visible-p)
    (when (fboundp 'copilot-clear-overlay)
      (copilot-clear-overlay)))
   ((cfg-tools/minuet-ghost-text-visible-p)
    (when (fboundp 'minuet-dismiss-suggestion)
      (minuet-dismiss-suggestion)))
   (t
    (keyboard-quit))))

(defun cfg-tools/copilot-chat-yank-pop-previous ()
  "Pop the previous yanked code block from `copilot-chat` history."
  (interactive)
  (copilot-chat-yank-pop -1))

(use-package copilot
  ;; We activate the copilot extension only if it is authorized on this computer.
  ;; This will prevent us from loading it if not in use:
  :if (cfg-tools/ai-copilot-authorized-p)
  :pin "MELPA Unstable"
  :after eca
  :init
  ;; Disable indentation offset warnings - Copilot will use existing indentation
  ;; See https://github.com/copilot-emacs/copilot.el/issues/312#issuecomment-2729052774
  (setq copilot-indent-offset-warning-disable t)

  ;; Disable buffer size warnings - prevents "file size exceeds copilot-max-char" warnings for large files
  ;; Not working yet. See https://github.com/copilot-emacs/copilot.el/issues/313
  (setq-default copilot-max-char-warning-disabled t)

  :custom
  ;; Provide valid settings structure to prevent "Cannot read properties of null (reading 'copilot')" error
  (copilot-lsp-settings '(:copilot ()))

  :config
  ;; Configure Copilot to use the server from our PATH
  (let ((copilot-server (executable-find "copilot-language-server"))
        (node-binary (executable-find "node")))

    ;; Add NODE_NO_WARNINGS=1 to environment for Copilot server, or it will spam warnings
    ;; about deprecated Node.js APIs on stderr that cause Copilot to malfunction.
    (setenv "NODE_NO_WARNINGS" "1")

    ;; Check Node.js version (Copilot requires >= 22.0.0)
    (if (or (not node-binary)
            (let* ((version-output (shell-command-to-string (concat node-binary " -v")))
                   (major-version (when (string-match "v\\([0-9]+\\)" version-output)
                                    (string-to-number (match-string 1 version-output)))))
              (< (or major-version 0) 22)))
        (progn
          (warn "Copilot disabled: Node.js v22+ required, found %s"
                (if node-binary (string-trim (shell-command-to-string (concat node-binary " -v"))) "none"))
          (setq copilot-server-executable nil))

      (if (and copilot-server node-binary)
          (progn
            (setq copilot-server-executable copilot-server)
            (message "Copilot: Using server at %s" copilot-server))
        (message "Copilot: No language server found. Run setup.sh to install locally.")
        (setq copilot-mode nil))))

  ;; Files to exclude from Copilot
  (defvar cfg-tools/copilot-excluded-files
    '("\\.env\\(\\..*\\)?$"
      "\\.config$"
      "\\.cfg$"
      "secret"
      "credential"
      "^id_rsa"
      "\\.key$"
      "\\.log$"
      "\\.tmp$"
      "\\.ini$"
      "\\.txt$")
    "List of regex patterns for files to exclude from Copilot.")

  (defun cfg-tools/copilot-kubernetes-sensitive-p ()
    "Return non-nil if current buffer contains Kubernetes sensitive content.
Returns non-nil if buffer contains Kubernetes Secrets or ConfigMaps."
    (save-excursion
      (goto-char (point-min))
      (and (re-search-forward "^apiVersion:" nil t)
           (goto-char (point-min))
           (re-search-forward "^kind:\\s-*\\(Secret\\|ConfigMap\\)\\s-*$" nil t))))

  (defun cfg-tools/copilot-excluded-file-p ()
    "Check if current file should be excluded from Copilot."
    (or
     ;; Check filename patterns
     (and buffer-file-name
          (let ((filename (file-name-nondirectory buffer-file-name)))
            (cl-some (lambda (pattern)
                       (string-match-p pattern filename))
                     cfg-tools/copilot-excluded-files)))
     ;; Check directory patterns
     (and buffer-file-name
          (string-match-p "/\\(dist\\|build\\|vendor\\)/" buffer-file-name))
     ;; Check content patterns
     (cfg-tools/copilot-kubernetes-sensitive-p)))

  (defun cfg-tools/safe-copilot-mode ()
    "Enable copilot-mode with silent error handling, excluding sensitive files.
Defers activation to ensure Copilot server is ready."
    (unless (or (file-remote-p (or (buffer-file-name) default-directory))
                (cfg-tools/copilot-excluded-file-p))
      (let ((buf (current-buffer)))
        (run-with-idle-timer
         0.5 nil
         (lambda ()
           (when (buffer-live-p buf)
             (with-current-buffer buf
               (condition-case err
                   (when (and (featurep 'copilot)
                              (boundp 'copilot-server-executable)
                              copilot-server-executable
                              (file-executable-p copilot-server-executable))
                     (copilot-mode 1))
                 (error
                  ;; Only report errors if copilot is loaded (real errors)
                  (when (featurep 'copilot)
                    (message "Copilot activation failed: %S" err)))))))))))

  :hook ((prog-mode . cfg-tools/safe-copilot-mode)
         (text-mode . cfg-tools/safe-copilot-mode)
         (markdown-mode . cfg-tools/safe-copilot-mode)
         (yaml-ts-mode . cfg-tools/safe-copilot-mode)
         (json-ts-mode . cfg-tools/safe-copilot-mode)
         (sh-mode . cfg-tools/safe-copilot-mode)
         (dockerfile-mode . cfg-tools/safe-copilot-mode)
         (css-mode . cfg-tools/safe-copilot-mode)
         (sql-mode . cfg-tools/safe-copilot-mode)
         (conf-mode . cfg-tools/safe-copilot-mode)))

** GitHub Copilot Chat
GitHub Copilot Chat provides an interactive chat interface with GitHub Copilot,
similar to what's available in VS Code or IntelliJ. This is a separate package
from the completion-only ~copilot.el~. It enables natural language interactions
with Copilot, allowing you to ask questions, request code explanations, generate
tests, and more, all within Emacs.

*** Features
- Interactive chat with GitHub Copilot
- Code explanation, review, and generation
- Multiple frontend options (Org-mode, Markdown, Shell-maker)
- Integration with your codebase context
- Transient menu interface for easy access

  command -v rtk >/dev/null 2>&1

install__tools__ai__rtk() {
  if ! is_installed__tools__ai__jq; then
    install_system_packages "jq"
  else
    log_skip "jq is already installed."
  fi
  if ! is_installed__tools__ai__rtk; then
    if curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh; then
      return 0
    else
      log_error "RTK installation failed."
      return 1
    fi
  else
    log_skip "RTK is already installed."
  fi
}

uninstall__tools__ai__rtk() {
  log_skip "RTK" "RTK might be in use by another tool in the system. If required, please uninstall it manually."
}
