* Description
Treemacs provides a file and project explorer sidebar for Emacs, integrating
with version control systems and icon themes to visualize project structure.

  (defun cfg-navigation/get-current-folder ()
    "Get the folder of the current buffer, but only for real Files or Dired."
    (let ((path (or (buffer-file-name)
                    (and (derived-mode-p 'dired-mode)
                         (fboundp 'dired-current-directory)
                         (dired-current-directory)))))
      (when path
        (file-name-as-directory (if (file-directory-p path) path (file-name-directory path))))))

  (defun cfg-navigation/treemacs-toggle ()
    "Toggle the visibility of the Treemacs window."
    (interactive)
    (declare-function treemacs-get-local-window "treemacs")
    (if (treemacs-get-local-window)
        (delete-window (treemacs-get-local-window))
      (treemacs)))

  (defun cfg-navigation/treemacs-set-root-to-current-folder (&optional target-folder)
    "Set the root of Treemacs to the folder of the current file or default directory."
    (let ((folder (or target-folder
                      (with-current-buffer (other-buffer (current-buffer) t)
                        (cfg-navigation/get-current-folder)))))
      (when (and folder (file-directory-p folder))
        ;; If this is a TRAMP path and a matching local path exists, prefer the
        ;; local path to avoid adding host:/docker:... entries when the intent
        ;; was to add the local project root. Otherwise keep the TRAMP path so
        ;; remote projects still work when intended.
        (when (and (fboundp 'tramp-dissect-file-name)
                   (file-remote-p folder))
          (condition-case _err
              (let* ((tfn (tramp-dissect-file-name folder))
                     (local (when tfn
                              (declare-function tramp-file-name-localname "tramp")
                              (tramp-file-name-localname tfn))))
                (when (and local (file-exists-p local))
                  (setq folder (file-name-as-directory (expand-file-name local)))))
            (error nil)))
        (when (and (file-remote-p folder)
                   (not (file-readable-p folder)))
          (message "Warning: remote path %s appears unreadable" folder))
        (ignore-errors
          (treemacs-select-window)
          (treemacs-do-add-project-to-workspace folder (file-name-nondirectory (directory-file-name folder)))
          (treemacs-refresh)))))

  (defun cfg-navigation/update-treemacs-faces-except (excluded-faces)
    "Update all Treemacs-related faces, excluding specified faces."

If you need to shrink or enlarge the treemacs window later with the keyboard,
you can use:

- =C-x {= - Shrink the window horizontally.
- =C-x }= - Enlarge the window horizontally.

Treemacs has also several useful shortcuts. A few examples:

| Key | Action                              | Description                                                           |
|-----+-------------------------------------+-----------------------------------------------------------------------|
| th  | treemacs-toggle-show-dotfiles       | Toggle the hiding and displaying of dotfiles.                         |
| ti  | treemacs-hide-gitignored-files-mode | Toggle the hiding and displaying of gitignored files.                 |
| tf  | treemacs-follow-mode                | Toggle treemacs-follow-mode.                                          |
| ta  | treemacs-filewatch-mode             | Toggle treemacs-filewatch-mode.                                       |
| tv  | treemacs-fringe-indicator-mode      | Toggle treemacs-fringe-indicator-mode.                                |
| td  | treemacs-git-commit-diff-mode       | Toggle treemacs-git-commit-diff-mode.                                 |
| =   | treemacs-fit-window-width           | Adjust the width of the treemacs window to that of the longsest line. |

See full list at [[https://github.com/Alexander-Miller/treemacs?tab=readme-ov-file#default-keymaps][this link]].
